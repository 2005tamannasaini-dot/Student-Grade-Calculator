# Student Grade Calculator

A beginner-friendly Python project that calculates students' total marks, percentage, grade, and pass/fail result.

## Features

- Accepts student name with validation
- Takes marks for Hindi, English, and Math
- Validates marks between 0 and 100
- Calculates total marks and percentage
- Assigns a grade based on percentage
- Displays PASS or FAIL
- Supports multiple students
- Handles invalid numeric input

## Technologies Used

- Python 3
- Functions
- Dictionaries
- Loops and conditional statements
- Exception handling

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the command:

   `python StudentGradeCalculator.py`

5. Enter the student name and marks when prompted.

## Grading Criteria

| Percentage | Grade |
|---|---|
| 90% and above | A |
| 75% to below 90% | B |
| 60% to below 75% | C |
| 33% to below 60% | D |
| Below 33% | F |
